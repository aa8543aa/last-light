# Realistic Combat Web

Babylon.js로 만드는 브라우저용 극사실주의 1인칭 전투 게임입니다. 중간고사 바이브 코딩 과제로 제작합니다.

> 현재 기획 단계이며, 아직 실행할 수 있는 빌드는 없습니다.

## 1. 제작한 것 소개

폐허가 된 실내 아레나에서 몰려오는 적을 1인칭으로 처치하며 버티는 게임입니다. 설치 없이 브라우저에서 바로 플레이할 수 있고, 사실적인 조명과 재질을 가장 중요한 목표로 삼습니다.

- 실행 방법: 구현 후 작성 (GitHub Pages 배포 예정)
- 조작법: 구현 후 작성

## 2. PRD

### 목표

- 브라우저에서 설치 없이 실행되는 전투 게임을 만든다.
- 실시간 렌더링으로 얻을 수 있는 최대한 사실적인 화면을 만든다.
- 일반 노트북에서도 플레이할 수 있는 성능을 유지한다.

### 엔진 선택: Babylon.js

처음에는 Three.js를 검토했으나 Babylon.js로 결정했습니다.

| 항목 | Babylon.js | Three.js |
| --- | --- | --- |
| 성격 | 게임 엔진에 가까움 | 범용 3D 렌더링 라이브러리 |
| 물리 | Havok 플러그인을 공식 지원 | 외부 라이브러리를 직접 연동 |
| 충돌, 입력, FPS 카메라 | 엔진에서 제공 | 대부분 직접 구현하거나 애드온 사용 |
| 후처리 | 기본 렌더링 파이프라인, SSAO, SSR 제공 | 애드온을 조합 |

사실감의 한계는 라이브러리보다 에셋 품질과 브라우저 성능에서 옵니다. 그래서 언리얼 엔진 수준의 화면을 목표로 잡지 않고, 작은 공간에 품질을 집중합니다.

### 핵심 기능

| 우선순위 | 기능 | 설명 |
| --- | --- | --- |
| 필수 | 1인칭 이동 | WASD 이동, 마우스 시점, 달리기, 벽 충돌 |
| 필수 | 사격 | 히트스캔 판정, 반동, 탄약, 재장전 |
| 필수 | 적 AI | 추적, 공격, 피격, 사망 |
| 필수 | 게임 흐름 | 시작, 웨이브 진행, 체력, 게임 오버, 재시작 |
| 필수 | 사실적 렌더링 | PBR 재질, HDRI 조명, 실시간 그림자, 톤 매핑, SSAO |
| 선택 | 전투 연출 | 총구 화염, 탄흔, 피격 효과, 입체 음향 |
| 선택 | 그래픽 옵션 | 저사양 기기를 위한 품질 단계 |

### 범위에서 제외

- 멀티플레이
- 3인칭 시점과 근접 전투
- 넓은 오픈 월드

### 기술 스택

- Babylon.js, Havok Physics
- Vite, TypeScript
- 에셋: 라이선스를 확인한 무료 에셋 (예: Poly Haven의 CC0 HDRI, 텍스처, 모델)
- 배포: GitHub Pages

### 완료 기준

- 배포된 URL에 접속해 시작부터 게임 오버, 재시작까지 플레이할 수 있다.
- 일반 노트북 기준 평균 30 FPS 이상을 유지한다.
- 사용한 에셋의 출처와 라이선스를 README에 기록한다.
